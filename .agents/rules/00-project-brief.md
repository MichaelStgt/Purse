\# Project Brief: **Application Name** "Purse"

\## Project Goals

\- Purse is a budgeting tracker can handle expense and income transactions, categorize transactions, and provide insightful visualizations of spending habits.

\- As People would not use an app that is time consuming, the app should be simple and easy to use. It should be a tool that helps users manage their finances without adding complexity to their lives.

\- Users should really know where your money is going and how to optimize your spending habits. Especially for bad habbits like drinking alkohol or smoking

\- Navigation inside the app should be intuitive and user-friendly, allowing users to easily access different features and sections of the app.

\## Architecture \& Stack

\- .NET MAUI 10.

\- C# 12.

\- CommunityToolkit.MVVM for MVVM pattern implementation.

\- CommunityToolkit.Datasync for data synchronization.

\- MVVMBaseTen for base MVVM classes and helpers.

\- LibraryTen for UI components and controls.


\## UI/UX Guidelines

\- Both Dark and Light mode design system.

\- Always prefer styles from Styles.xaml and colors from ApplicationColors.xaml.

\- Use "Primary" accent color for Dark mode and "PrimaryDark" for Light mode.



\## Core Coding Standards

\- Modern .NET 10 C# conventions.

\- Strict enforcement of `StyleCop.Analyzers` rules: no underscores in private fields, mandatory `this.` prefix for class members.

\- Utilize standard LibraryTen component patterns for UI elements.
